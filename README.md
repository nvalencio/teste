# Ping Pong

Jogo de Ping Pong para dois jogadores em Python (tkinter, sem dependências externas).

## Como jogar

    python pingpong.py

| Jogador  | Subir | Descer |
|----------|-------|--------|
| Esquerdo | W     | S      |
| Direito  | ↑     | ↓      |

- A bola acelera a cada rebatida; o ângulo depende de onde ela toca na raquete.
- Vence quem chegar a 7 pontos. Pressione **R** para reiniciar.
